# 베타 패치 노트 - v0.113.0

지금까지 중 가장 큰 베타 패치입니다. 새 캐릭터 [gold:character]풀[/gold], 새 게임 모드 [gold]블리츠[/gold]와 [gold]드레드[/gold], 새 이벤트·카드·유물, 밸런스 변경, UX 개선, 새 아트와 오디오, 그리고 많은 버그 수정이 포함됩니다.

[devnote]드디어 지금까지 중 가장 큰 (베타) 패치가 나왔습니다! 이 패치는 게임의 베타 브랜치 전용입니다. 메인 브랜치로 가기 전에 많은 테스트가 필요한, 영향이 큰 콘텐츠가 들어 있기 때문입니다. 베타 브랜치로 옮기려면 라이브러리에서 Slay the Spire 2를 우클릭하고 속성 → 게임 버전 및 베타에서 `public-beta`를 고르면 됩니다. 메인 브랜치는 이전의 더 안정적인 베타 버전인 v0.111.0의 모든 콘텐츠와 변경 사항으로 업데이트됩니다. 그러니 메인 브랜치에서 아래 콘텐츠가 보이지 않아도 놀라지 마세요.[/devnote]
[devnote:en]At long last, the biggest (beta) patch yet is here!!! Reminder that this patch is exclusive to the beta branch of the game as we've got some really impactful bits of content that will require lots of testing before they reach the main branch. Reminder that if you'd like to swap over to the beta branch, you can do so by right-clicking on Slay the Spire 2 in your library and navigating to Properties -> Game Versions & Betas and selecting `public-beta` from the dropdown. The main branch will be brought up-to-date with all content and changes in the previous, more stable beta version, v0.111.0. So don't be confused that the following content isn't there if you boot up the main branch.[/devnote]
