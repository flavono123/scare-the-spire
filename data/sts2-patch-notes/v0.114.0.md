# Beta Patch Notes - v0.114.0

A beta patch centered on [gold:character]The Fool[/gold], with lots of reworks, buffs and nerfs, a brand new card, a few art additions, and tons of bug fixes.

- Changed the [gold:power]Hard to Kill[/gold] power: it now only counts HP loss, not damage to Block (meaning this power does not work on blocked damage).

## Bug Fixes

### General

- If you remove or transform all your cards enchanted with [gold:enchantment]Clone[/gold], the Clone rest site option no longer shows up.
- Fixed a Block card with [gold:enchantment]Adroit[/gold] enchantment counting as 2 separate Block gains to the [gold:power]Unmovable[/gold] power.
- Can no longer change ascension via controller hotkeys in custom [gold]Dread[/gold] screen.
- Fixed hovertip of the initial [gold]Blitz[/gold] shop token not appearing when using controller.
- Hotkeys no longer press buttons on menus that are closed or hidden, and the pause menu keeps blocking hotkeys after you inspect a card or relic from it.
- Hotkeys no longer reach the screen behind an open popup or error message.
- A tutorial that couldn't appear because another popup was already open now shows later instead of being skipped for good.
- Older runs no longer disappear from Run History after playing on another computer or reinstalling Steam.

### Enemies

- Fixed the impaled arrow on [gold:encounter]Test Subject[/gold] being very small.
- Fixed controller nav breaking if you are hovering over the [gold:monster]Fat Gremlin[/gold] when it runs away.
