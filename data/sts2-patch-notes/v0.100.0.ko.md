# 베타 패치 노트 - v0.100.0

[devnote]출시 이후 첫 대형 패치입니다. 무한 콤보를 더 어렵게 만드는 밸런스 패스가 핵심이고, 공포증 모드와 대체 아트도 들어갑니다. 지금은 베타 브랜치 전용입니다.[/devnote]
[devnote:en]Welcome to the first BIG post-launch patch, Slayers!! This one has a huge balance pass, the main aim of which is to make infinites harder to achieve. We're also introducing a Phobia Mode with bespoke assets that should mitigate various creepy phobia concerns. Reminder that this patch is exclusive to the beta branch for now. It will come to the main branch later, likely with some more tweaks![/devnote:en]
