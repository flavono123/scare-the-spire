# 베타 패치 노트 - v0.110.0

새로운 베타 패치가 도착했습니다! 이번 패치에는 다양한 밸런스 변경과 리워크가 포함됩니다.

특히 [gold:card]신기루[/gold]와 [gold:card]창조의 기둥[/gold]이 각각 소폭 상향·하향된 채 v0.109.0 이전 버전으로 돌아갑니다. 키보드 전용 조작, 여러 카드의 정식 초상화, 각 캐릭터 고유 형태의 VFX도 추가됩니다.

## 사용자 인터페이스 및 경험

### 일반

- 키보드 전용 모드를 지원합니다.
- 지도 전체를 스크린샷으로 찍는 "공유" 버튼을 지도 화면에 추가했습니다.
- 입력 또는 키 설정을 변경할 때 "입력 대기 중" 팝업을 표시합니다.
- 입력 재설정 화면의 여백, 글꼴 크기, 색상을 조정했습니다.
- 여러 버튼의 입력 글리프 위치를 조정했습니다.
- 프로필 변경 버튼의 입력 글리프를 더 크게 표시합니다.
- 키보드 모드 글리프 임시 이미지를 게임 스타일에 맞는 에셋으로 교체했습니다.
- 상단 바 단축키 아이콘의 크기와 위치를 조정했습니다.
- 선택 조준점 에셋의 대비와 해상도를 높이고 표시 크기를 줄였습니다.
- 입력 설정에서 지정되지 않은 키는 회색 하이픈으로 표시합니다.
- Steam Input 활성화 여부를 더 명확히 표시합니다.
- 비표준 화면 비율에서 설정 스크롤바의 위치를 개선했습니다.
- 컨트롤러 사용 시 [gold:relic]날개 달린 부츠[/gold]를 보유했다면, 지도를 열 때 현재 노드와 연결된 노드에 우선 포커스를 맞춥니다.
- 아직 도전과제 화면이 없어 통계 화면의 좌우 페이지 이동을 비활성화했습니다.

### 멀티플레이어

- 친구의 런에 참가하는 UI를 개선했습니다.
- [gold:card]가르침[/gold]을 사용하면 이미 턴을 종료한 대상의 턴이 다시 활성화됩니다.

## 버그 수정

### 일반

- 고급 카드가 의도대로 조금 더 자주 등장합니다.
- 특정 상황에서 카드의 섞인 순서를 알아낼 수 없도록 수정했습니다.
- 울트라와이드 화면에서 런 기록을 중앙에 배치했습니다.
- 런 종료 시 얻은 시대 해금이 사라져 시간선 진행을 영구적으로 막던 문제를 수정했습니다. 영향을 받은 저장 데이터는 불러올 때 복구됩니다.
- 게임 오버 애니메이션 중 화면을 벗어나면 필요한 점수를 소모하지 않고 시대가 해금되던 문제를 수정했습니다.
- 카드 도감에서 카드를 살펴볼 때 컨트롤러 포커스가 카드 목록으로 이동하던 문제를 수정했습니다.
- 포션 팝업을 Escape로 닫을 때 설정 화면이 함께 열리던 문제를 수정했습니다.

### 적

- [gold:monster]만각지네[/gold]의 도감 능력치가 올바르게 표시됩니다.
- 도감에서 [gold:monster]튼튼한 알[/gold]이 부화할 때 오류가 발생하던 문제를 수정했습니다.

### 멀티플레이어

- 다른 플레이어가 [gold:potion]광기의 손길[/gold]을 건넬 때 선택한 카드가 멈추던 문제를 수정했습니다.

- [gold:card]모방 학습[/gold]이 Replay와 함께 사용될 때 더 이상 진행이 멈추지 않으며 중복 사용을 무시합니다.
- [gold:card]가르침[/gold]이 Replay와 함께 사용될 때 진행이 멈추던 문제를 수정했습니다.
