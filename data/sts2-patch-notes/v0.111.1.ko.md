# 메이저 업데이트 #3 - v0.111.1

세 번째 메이저 메인 브랜치 업데이트가 도착했습니다. v0.108.0~v0.111.0의 모든 콘텐츠, 아트, 밸런스 변경, 버그 수정이 담겨 있습니다. 이번 업데이트는 특히 화려합니다. 캐릭터 형상 전용 VFX, 낮은 체력 대기 애니메이션, [gold]구체[/gold] 패시브 VFX, 많은 역사 아트 등이 추가되었습니다. [gold:monster]영겁의 모래시계[/gold]가 움직입니다. 7월 니오우스레터에서 소개된 애니메이션을 이제 모든 플레이어가 볼 수 있습니다. 그 밖에 번체 중국어와 인도네시아어, 키보드 전용 모드, 새 니오우 유물, 캐릭터별 멀티플레이어 카드 대량 추가, 수많은 밸런스 변경이 있습니다.
[devnote]세 번째 메이저 메인 브랜치 업데이트가 드디어 나왔습니다. v0.108.0~v0.111.0의 모든 내용이 들어 있으니 베타 브랜치 플레이어에게는 새로울 것이 없습니다. 지금 베타 브랜치의 새 캐릭터와 게임 모드가 화제지만, 메인 브랜치에 오기까지는 테스트와 다듬기가 훨씬 더 필요하고 언제가 될지는 아직 모릅니다. 더 안정적인 경험을 원한다면 오늘의 알찬 콘텐츠(베타 패치 4개 분량)를 즐겨 주세요.[/devnote]
[devnote:en]It's time, Slayers! The third major main branch update is finally here, bringing all of the content, art, balance changes, and bug fixes from v0.108.0-v0.111.0! So if you're a beta branch player, this won't be relevant to you. While the new character and game modes on the current beta branch are the talk of the town right now, all that stuff will need to be tested and polished up quite a bit more before it reaches the main branch. We're not sure when that will be. But for those of you seeking a more stable experience, we've got lots of juicy content for you today (4 whole beta patches worth).[/devnote]

### 일반

- 턴 종료 시 발동하는 [gold]구체[/gold] 패시브가 이제 [gold:power]종말[/gold]보다 먼저 발동합니다. 예를 들어 [gold:card]정신 폭주[/gold] 카드 등으로 자신에게 [gold:power]종말[/gold]을 걸어 죽게 되더라도, 턴 종료 패시브를 가진 [gold]구체[/gold]([gold]전기[/gold] [gold]구체[/gold]로 체력 3인 적을 처치하는 경우 등)가 마지막 적을 처치하면 전투에서 패배하지 않고 승리합니다.

## 모딩

- 모드를 처음 켜서 실행하면 모드 미적용 저장 파일이 모드 저장 폴더로 복사되며, 과정을 설명하는 팝업이 표시됩니다.
- 이전에 모드 불러오기를 거절한 플레이어의 모드 미적용 저장 파일이 복사되지 않던 문제를 고쳤습니다.
- 모드 불러오기를 거절했지만 모드를 설치해 둔 플레이어의 저장 파일은 더 이상 모드 저장 폴더로 복사되지 않습니다.
- 같은 모드를 쓰는 플레이어끼리 멀티플레이어에서 "버전 불일치"가 나던 문제를 고쳤습니다(도움을 준 RitsuLib의 OLC 감사합니다!).
- 직렬화 캐시를 리플렉션 대신 ModelDb에서 만듭니다.
- 콘텐츠를 타입 이름 대신 ModelId로 정렬합니다.
- 정렬 시 동순위 판별 기준을 더 사용합니다.
- ModelIdSerializationCache에서 역사 ID를 정렬합니다.
- 게임플레이에 영향을 주지 않는 모델을 ModelIdSerializationCache 해시에서 제외합니다.
- SavedPropertySerializationCache를 ModelIdSerializationCache에 병합했습니다. SavedProperty가 이제 해시에 포함되며, 모드의 SavedProperty ID가 멀티플레이어용으로 올바르게 정렬됩니다.
- affectsGameplay가 false인 모드의 콘텐츠가 ID 맵의 끝으로 정렬됩니다.
- 게임플레이와 무관한 모드 불일치 경고에 올바른 모드 목록이 기록됩니다.
- 모딩 메뉴에 컨트롤러 지원이 추가되었습니다.
- Steam 모드 때문에 ReflectionHelper.ModTypes가 아무것도 반환하지 않던 문제를 고쳤습니다.
- 모드가 여러 어셈블리를 등록할 수 있습니다.
- SerializableSave.NumReloads가 이제 피어 간에 일관됩니다.
- 버전이 더 높으면 Steam 모드가 로컬 모드보다 우선합니다.
- 브랜치 지원 여부를 확인하는 Steam 워크숍 호출을 묶어 처리해 모드가 더 빨리 불러와집니다.
- STS2.dll XML 문서 공개를 시작했습니다.
- 세션의 어느 플레이어라도 모드를 쓰면 오류 창에 "버그 신고" 버튼이 표시되지 않습니다.
