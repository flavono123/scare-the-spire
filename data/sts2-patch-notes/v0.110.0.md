# Beta Patch Notes - v0.110.0

Another beta patch just dropped! This one contains a host of balance changes and reworks.

Most notably, [gold:card]Mirage[/gold] and [gold:card]Pillar of Creation[/gold] have been reverted to their pre-v0.109.0 versions, with a slight buff and nerf respectively. This patch also introduces keyboard-only controls, polished portrait art for several cards, and VFX for each character's unique form.

## Content & Balance

### Ancients

- [gold:card]Abundance[/gold] ([green][sine]buff[/sine][/green]):
  - Now always creates Upgraded Powers.
  - Its upgrade now lowers its Energy cost by 1.
- Reworked [gold:relic]Toasty Mittens[/gold]: "At the start of your turn, Exhaust the top card of your Draw Pile and gain 1 Strength." -> "At the start of your turn, Exhaust 1 card from your Hand and gain 1 Strength."
- [gold:relic]Seal of Gold[/gold] ([green][sine]buff[/sine][/green]): Gold loss decreased from 5 -> 3.
- Changed [gold:relic]Beautiful Bracelet[/gold]:
  - Cards enchanted increased from 3 -> 4.
  - [gold:enchantment]Swift[/gold] amount decreased from 3 -> 2.
- [gold:relic]Fur Coat[/gold] ([green][sine]buff[/sine][/green]): marked combats increased from 7 -> 8.
- [gold:relic]Signet Ring[/gold] ([red][jitter]nerf[/jitter][/red]): Gold decreased from 999 -> 888.
- [gold:card]Relax[/gold] ([green][sine]buff[/sine][/green]): Block increased from 15(17) -> 16(18).
- [gold:card]Tanx's Whistle[/gold] ([green][sine]buff[/sine][/green]): cost decreased from 3 -> 2.
- [gold:card]Maul[/gold] ([green][sine]buff[/sine][/green]): damage scaling increased from 1(2) -> 2(3).
- [gold:relic]Fiddle[/gold] ([red][jitter]revert[/jitter][/red]): card draw decreased again from 3 -> 2.

### Ironclad

- [gold:card]Mangle[/gold] ([green][sine]buff[/sine][/green]): damage increased from 15(20) -> 20(26).
- [gold:card]Pact's End[/gold] ([green][sine]buff[/sine][/green]): damage increased from 17(23) -> 18(24).

### Silent

- Reworked [gold:card]Haze[/gold]: Uncommon Skill, cost 3, "Sly. Apply 4(6) Poison to ALL enemies." -> Uncommon Skill, cost 2, "Apply 4(6) Poison and 1(2) Weak to ALL enemies."
- Reworked [gold:card]Outbreak[/gold] into a Rare Skill: Uncommon Power, cost 1, "Whenever you apply Poison, deal 4(5) damage to ALL enemies." -> Rare Skill, cost 3, "Apply 9(12) Poison to ALL enemies. Poison triggers immediately."
- Reworked and renamed [gold:card]Scare[/gold] -> [gold:card]Sidestep[/gold]: Uncommon Skill, cost 0, "Apply 1 Weak to ALL enemies. Exhaust. (Lose Exhaust.)" -> Uncommon Skill, cost 0, "Next turn, gain 1(2) Energy."
- Changed [gold:card]Mirage[/gold]:
  - Reverted to its previous version, gaining Block based on the [gold:power]Poison[/gold] on enemies again.
  - No longer Exhausts.
- [gold:card]Well-Laid Plans[/gold] ([red][jitter]nerf[/jitter][/red]): cost increased from 1(0) -> 2(1).
- [gold:card]Echoing Slash[/gold]: rarity decreased from Rare -> Uncommon.

### Regent

- Reworked [gold:relic]Regalite[/gold]: "Whenever you create a card, gain 2 Block." -> "The first time you create a card each turn, gain 6 Block."
- [gold:card]Terraforming[/gold] ([green][sine]buff[/sine][/green]): Vigor increased from 6(8) -> 7(10).
- Changed [gold:card]Pillar of Creation[/gold]:
  - Reverted to its previous version, so its effect is no longer limited to once per turn.
  - Block decreased from 3(4) -> 2(3).
- [gold:card]Crush Under[/gold] ([green][sine]buff[/sine][/green]): damage increased from 7(8) -> 8(9).

### Necrobinder

- Changed [gold:card]Eidolon[/gold]: can no longer be generated mid-combat.
- [gold:card]Sacrifice[/gold] ([green][sine]buff[/sine][/green]): Block gain increased from double -> triple Osty's Max HP.
- [gold:card]The Scythe[/gold] ([green][sine]buff[/sine][/green]): damage scaling increased from 4(5) -> 5(7).

### Defect

- [gold:card]Biased Cognition[/gold] ([green][sine]buff[/sine][/green]): Focus increased from 4(5) -> 5(6).
- [gold:card]Refract[/gold] ([green][sine]buff[/sine][/green]): damage increased from 9(12) -> 10(13).
- [gold:card]Rocket Punch[/gold] ([red][jitter]nerf[/jitter][/red]): "Whenever you create a Status, reduce this card's cost to 0 Energy until played." -> "Whenever you create a Status, reduce this card's cost by 1 Energy until played."
- [gold:card]Synchronize[/gold] ([green][sine]buff[/sine][/green]):
  - Its upgrade now increases temporary Focus from 2 -> 3.
  - No longer Exhausts.

## User Interface & Experience

### General

- Added support for keyboard-only mode.
- Added a "Share" button to the map screen that takes a screenshot of the entire map.
- Added a "Listening For Input" popup while remapping inputs or bindings.
- Updated the padding, font sizes, and colors on the input remap screen.
- Updated input glyph positioning on various buttons.
- Updated the change profile button to render a larger input glyph.
- Replaced the keyboard-mode glyph placeholder with an asset matching the game's style.
- Adjusted the hotkey icon's size and position in the top bar.
- Updated the generic selection reticle asset for better contrast and resolution, and rendered it slightly smaller.
- Missing bindings now render a gray hyphen in input settings.
- The game now states more explicitly whether Steam Input is active.
- Improved the settings scrollbar placement at non-standard aspect ratios.
- With a controller, the map now initially tries to hover a node connected to the current one when the player has [gold:relic]Winged Boots[/gold].
- Disabled left/right paging on the Stats screen because the Achievements screen does not exist yet.

### Multiplayer

- Improved the UI for joining a friend's run.
- [gold:card]Tutor[/gold] now un-ends the target's turn if they had ended it.
- Removed the "Waiting for Players" screen when dying to [gold:monster]Architect[/gold].

## Bug Fixes

### General

- Uncommon cards now appear slightly more often, as intended.
- Players can no longer discern the shuffle order of cards in certain scenarios.
- Run History is now centered on ultrawide screens.
- Fixed an Epoch unlock earned at the end of a run being lost and permanently blocking Timeline progress. Affected saves are repaired when loaded.
- Fixed leaving the game-over screen mid-animation granting an Epoch unlock without spending the required score.
- Fixed controller navigation reaching the card grid while inspecting a card in the Compendium.
- Fixed the settings screen opening when Escape was pressed to close the Potions popup.

### Enemies

- [gold:monster]Tough Egg[/gold] can now have 1 more Max HP.
- [gold:monster]Decimillipede[/gold] now displays its stats correctly in the Bestiary.
- Fixed an error when [gold:monster]Tough Egg[/gold] hatched in the Bestiary.

### Events

- Fixed a typo in the [gold:event]Lantern Key[/gold] event.

### Potions & Relics

- [gold:relic]Bellows[/gold] now properly upgrades the extra card when [gold:relic]Pendulum[/gold] triggers on turn 1.
- Fixed [gold:card]Dowsing[/gold] not previewing [gold:card]Abundance[/gold].

### Ironclad

- Fixed [gold:card]Juggling[/gold] so that when the third Attack also auto-plays an Attack, such as [gold:card]Uproar[/gold], it copies the original Attack instead of the auto-played Attack.

### Multiplayer

- Fixed a chosen card getting stuck if another player gives you [gold:potion]Touch of Insanity[/gold].
- [gold:card]Feral[/gold] now puts [gold:card]The Ball[/gold] into your Hand instead of another player's.
- [gold:card]Imitation Learning[/gold] no longer softlocks with Replay and now ignores duplicate plays.
- [gold:card]Tutor[/gold] no longer softlocks with Replay.
- Players can Abandon Run outside of combat again.

## Modding

- The "Report Bug" button is no longer shown in error dialogs when any player in the session has mods.
