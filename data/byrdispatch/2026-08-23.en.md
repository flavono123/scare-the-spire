# 2026-08-23

## Stories

![Theme picker in Profile](/images/byrdispatch/2026-08-23/profile-theme-picker.png)

- Light theme is now available. You can change the theme from Profile in the top-right bar. (new)(thanks for the report)
- Parts of the existing dark theme were also adjusted for light-theme compatibility. Dark theme remains the default and the recommended option.
- Likes are now unified. The reaction palette and Rune Pyramid likes that only applied to Stories have been removed.

## Patch Notes

- Ascension numbers in patch bodies now link to the Compendium.
- Hovering a relic now shows the in-game stone slab. (bug)

## History Course (Beta)

![Multiplayer replay top bar](/images/byrdispatch/2026-08-23/history-course-party-topbar.png)

- Multiplayer run history is now supported (new)(thanks for the report)
- In replay or run info (the cog in the top right), picking a player character from the top-left profile switches replay and info to that character.
- Duplicate characters get ordinals in order.

![Multiplayer character-style thumbnail](/images/byrdispatch/2026-08-23/history-course-party-cover.png)

- Character-style thumbnails split to show every player character.
