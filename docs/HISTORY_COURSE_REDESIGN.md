# 역사 강의서 개편안

슬레이 더 스파이어 커뮤니티가 런을 공유할 때 쓰는 **중괄호형 유튜브 썸네일 문법**을 인덱스·코오오옴보 참조 표지로 옮긴다. AI 판정·추천 피드·조합 사전 운영은 하지 않는다.

학습 스크랩·공출현 덤프는 gitignore된 [`research/history-course-covers/`](../research/history-course-covers/)에 둔다. 문구·요소 조합 스펙은 같은 경로의 `LOGIC.md`가 SSOT다.

## 세 축

| # | 축 | 상태 |
| --- | --- | --- |
| 1 | 인덱스(+ 코오오옴보 참조)에서 보이는 **유튜브형 표지** | **진행 중** |
| 2 | 상세 리플레이 시 **재미 증대** | 이후 |
| 3 | 상세 리플레이 시 **복기 기능 강화** | 이후 |

축 2·3은 제목만 남긴다. 표지 문법이 먼저 고정된 뒤 상세 동선을 붙인다.

---

## 축 1 — 표지

### 문법 (3층)

1. **배경 아트**
2. **도전 이력의 핵심 문구** (한 줄)
3. **핵심 게임 요소 1–3** (카드·유물·포션 등; 같은 타입·같은 카드 반복 허용)

참고 문법: 원인 쪽 `{ 카드·유물 }` + 결과 한 줄(`∞` / 큰 숫자 / “보통 X가 아니다”). 슬갤·중괄호 계열 제목에서 반복되는 패턴이며, 표본 URL은 `research/history-course-covers/sources.md`에 둔다.

### 업로드 시 후보 2안

배경만 갈라진 두 인덱스를 제안하고, **1번을 자동 저장**한다.

| 안 | 배경 | 요소 |
| --- | --- | --- |
| 1 (기본) | 런 캐릭터 아트 | 가중 랜덤 1–3 |
| 2 | 핵심 카드의 베타 아트 (`cards-beta/`, 없으면 정식 `cards/`) | 같은 풀에서 뽑되 **배경 카드 id는 요소에 넣지 않음** |

문구·요소는 **런 내 가중 + 정적 콤보 공출현 테이블**로 뽑는다. 트렌드 AI·수동 메타 매핑은 쓰지 않는다. 유저가 문구/요소/배경을 바꾸거나 “다시 섞기” 할 수 있다. 안 건드려도 인덱스는 예쁘게 나와야 한다.

### 시각

- 폰트: 사이트 locale 폰트(`.font-game-title` 등). 중괄호 전용 폰트 미도입.
- 외곽: 흰 굵은 outline 정도만 참고.
- 색: [`.spire-*`](../src/app/globals.css) — 캐릭터 필은 캐릭터색, 요소 강조는 `spire-gold`.
- 렌더: 이미지 생성물 아님. 기존 webp를 조립한 DOM(`aspect-video`). Cloudflare Worker에서 파싱·이미지 작업 없음.
- 재사용: 역사 강의서 인덱스와 코오오옴보의 history-run 참조가 같은 표지 컴포넌트를 쓴다.

### 저장 (구현 시)

가칭 `cover_spec` jsonb. 인덱스는 raw `.run`을 다시 파싱하지 않고 표지 스펙만 읽는다. 상세는 [`LOGIC.md`](../research/history-course-covers/LOGIC.md).

### 하지 않음 (축 1)

AI 분석/생성, 자동 하이라이트 점수, 지속 갱신 휴리스틱 사전, 동적 OG 이미지, Worker 런타임 이미지 렌더, 추천 피드.

### 성공 지표 (축 1)

- 공개 런의 상세 진입률
- (선택) 자동 표지 대비 커스텀 표지 비율

## 축 2 — 상세 리플레이 재미 (이후)

표지가 약속한 “왜 볼지”가 재생 중에도 끊기지 않게 하는 축. 범위는 축 1 안정화 후 별도 브리프.

## 축 3 — 복기 기능 강화 (이후)

층별 관측값·댓글 동선 등. `.run`에 없는 전투 중 상세를 지어내지 않는 제약은 유지한다.
