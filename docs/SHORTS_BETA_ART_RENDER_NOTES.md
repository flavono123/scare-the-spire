# 쇼츠 "베타 아트" 시리즈를 위한 서비스 렌더 메모

`~/P/slseoun-shorts`의 "베타 아트{n}" 쇼츠(정식 아트 → 베타 아트 → 베타 확대)는 이 사이트의 백과사전 상세 페이지를
`pnpm shorts:capture`로 찍어 쓴다. 계획에 넣어 둔 것이고 아직 만들지 않았다. 아래는 그 계획에 맞춰 서비스 렌더를
고쳐야 하는 항목이다. 조사는 하지 않았고, 기준만 적는다.

| 요소 | 서비스 렌더 기준 |
| --- | --- |
| 고대의 존재 | 화면 구성을 게임과 같게 바꿔야 한다. 쇼츠가 게임 화면처럼 보여야 하므로 지금의 백과사전 레이아웃을 그대로 찍지 않는다. |
| 몬스터 | 요구사항을 아직 모른다. 서비스 페이지에 실제로 대어 보고 정한다. |
| 연대기(epoch) | 게임과 같게 만들 필요가 없다. 지금의 서비스 렌더로 충분하다. |

- 이벤트는 이 목록에 없다. 사이트에 이벤트 베타 그림이 없다.
- 쇼츠 산출물(PNG, 영상)은 이 저장소에 두지 않는다. 캡처 결과는 `~/P/slseoun-shorts`로 간다.
- 캡처 옵션과 시리즈 설계는 `~/P/slseoun-shorts/docs/beta-art.md`에 있다.
