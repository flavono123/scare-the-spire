# 정렬 퍼즐 레퍼런스 스터디 (작업 메모)

* **상태:** 질문 단계의 작업 메모다. 결정이 아니다. 질문 답을 받은 뒤 `concepts_brief.md`로 옮겨 확정한다.
* **날짜:** 2026-11-14
* **아직 못 찾은 것:** "눈누" 사이트. 검색하면 무료 한글 글꼴 사이트 눈누만 나온다. 주소를 받아 다시 본다.

## 1. 이 장르를 한 줄로

"같은 색끼리 한 곳에 모은다. 단, 임시로 둘 자리가 모자라다."

색을 모으는 것 자체는 어렵지 않다. 난이도는 전부 **빈 자리가 부족하다**는 데서 나온다. 빈 병이 하나 더 있으면 쉬워지고, 하나 줄면 막힌다. 이 장르의 레벨 디자인은 대부분 이 빈 자리 수와 색 수를 조절하는 일이다.

## 2. 장르의 두 갈래

### A. 붓기형: 물 정렬, 공 정렬, 모래 정렬, 나사 정렬

물 정렬(Water Sort) 규칙이 사실상 표준이다. 공·모래·나사 정렬은 재료만 바꾼 같은 규칙이다.

- 병이 N개 있고, 병마다 4칸이 들어간다.
- 색이 k개, 색마다 4칸씩 있고, 빈 병이 보통 2개 더 있다. (색 9개면 병 11개)
- 병 하나를 누르고 다른 병을 누르면, 위쪽에 붙어 있는 같은 색 덩어리가 들어갈 수 있는 만큼 옮겨진다.
- 받는 병은 비어 있거나, 맨 위 색이 같아야 한다. 아니면 그냥 안 옮겨진다.
- 모든 병이 한 색으로 꽉 차거나 비어 있으면 클리어.
- 실패는 "더 둘 곳이 없다"뿐이다. 시간 제한이 없고, 되돌리기나 다시 시작으로 빠져나온다.

모래 정렬(Sand Sort)은 이 규칙 그대로에 연출만 모래다. 붓는 동안 알갱이가 흘러내리고, 병이 다 차면 꽃이 핀다. 되돌리기는 판당 5번으로 제한된다. ([1001games](https://www.1001games.com/think/sand-sort-puzzle))

**왜 설명이 필요 없나:** 처음 보는 사람도 두 번 눌러 보면 규칙을 안다. 틀린 움직임은 막혀서 일어나지 않으니, 규칙을 몰라도 규칙을 어길 수 없다.

### B. 흐름형: Sand Loop, Loop Sort (2025년 유행)

붓기형과 구조가 다르다. "어디에 둘까"가 아니라 **"무엇을 먼저 꺼낼까"**를 고르고, 나머지는 자동으로 흘러간다.

- **Sand Loop:** 화면 위에 색 모래로 된 그림이 있고, 아래 대기열에 양동이들이 있다. 양동이를 컨베이어의 슬롯 5칸에 올리면, 그림 맨 아래 층의 같은 색 모래가 흘러 들어간다. 양동이가 100% 차면 터지면서 슬롯이 빈다. 5칸이 덜 찬 양동이로 꽉 찼는데 떨어지는 모래와 맞는 색이 없으면 실패. 뒤집힌 양동이는 앞의 양동이를 먼저 빼야 열린다. 아이템은 즉시 채우기·자석·섞기. ([easegame](https://easegame.com/blog/beyond-water-sort-sand-loop-new-king-color-matching-puzzles))
- **Loop Sort:** 트럭을 누르면 색 큐브가 순환 컨베이어로 쏟아지고, 같은 색 칸으로 저절로 정렬된다. 장애물로 가려진 블록(물음표), 커튼, 얼음, 방벽, 열쇠·자물쇠가 레벨마다 하나씩 추가된다. ([App Store](https://apps.apple.com/kr/app/loop-sort/id6751101794), [mwm.ai](https://mwm.ai/apps/loop-sort/6751101794))

**A와 B의 차이:**

| | A. 붓기형 | B. 흐름형 |
| :-- | :-- | :-- |
| 한 번 누르면 | 한 덩어리가 한 병으로 이동 | 여러 개가 쏟아져 자동으로 흘러감 |
| 정보 | 판 전체가 다 보인다 | 대기열 뒤쪽이 가려져 있다 |
| 시간 | 멈춰 있다 (턴제) | 흐르는 동안 기다린다 |
| 실패 | 막힘. 되돌리면 끝 | 슬롯이 넘치면 판이 끝남 |
| 손맛 | 생각하는 맛 | 쏟아지고 터지는 걸 보는 맛 |
| 만들기 | 규칙 단순, 풀 수 있는 판 생성이 핵심 | 흐름 애니메이션과 타이밍이 핵심 |

| 7 | 광고, 코인, 부스터 구매, 목숨 | 수익 장치 | 버림 | 사이트에 결제가 없다 |
| 8 | 레벨 수천 개를 파일로 | 콘텐츠 양 | 버림 | Cloudflare 정적 파일 한도 (`docs/CLOUDFLARE_LIMITS.md`). 판은 시드 숫자로 코드에서 만든다 |

## 5. 이 장르의 함정

- **풀 수 없는 판:** 색을 무작위로 섞으면 풀 수 없는 판이 나온다. 다 정렬된 상태에서 거꾸로 섞어 만들거나, 풀이 프로그램으로 확인해야 한다. 구현 범위에 바로 영향을 준다.
- **판이 다 비슷함:** 색 수만 늘리는 난이도는 열 판쯤 지나면 같은 일의 반복이 된다. 레퍼런스들이 장애물을 계속 추가하는 이유다.
- **색 구분:** 색각 이상이 있는 사람은 비슷한 색을 못 가린다. 포션 중에도 빨강 계열이 여럿이다. 색 말고 모양(아이콘)으로도 구분돼야 한다. 슬더스 애셋이 그냥 색 칸보다 나을 수 있는 지점이다.
- **휴대폰 화면:** 병 11~14개가 320px 폭에 들어가야 한다.
- **슬더스 사이트에 있을 이유:** 다른 두 게임(스무고개, 오토체스)과 달리 이 게임은 슬더스를 몰라도 할 수 있다. 그건 장점(누구나 함)이자 약점(이 사이트에 있을 이유가 옷뿐)이다.
