# Task 011: 게임에 안 나오는 데이터마이닝 항목 표시

## 상태: TODO (요구사항만 정리됨, 2026-11-19)

## 목표

백과사전에는 보이지만 실제 게임에서는 볼 수 없는 항목(번역 파일·코드에만 있고 게임이 쓰지 않는 것)에
"게임에서는 볼 수 없는 데이터마이닝 결과"라고 알리는 표시와 툴팁을 단다. 항목을 지우지 않는다.
지울지는 사용자가 나중에 항목별로 정한다.

## 배경

2026-11-19 관련 리소스 전수 조사 중 디컴파일한 `sts2.dll`(`/tmp/sts2-src`)과 백과사전 데이터를 대조해 찾았다.
판정 기준은 "게임 코드가 그 키나 클래스를 쓰는 곳이 없다"이다.
`AbstractModelSubtypes.cs`(모든 모델 클래스를 나열한 등록 파일)와 Mocks·AutoSlay·DevConsole에서만 쓰이는 경우는 제외했다.

참고(대상 아님):
- 카드·유물·포션·인챈트·이벤트(클래스 단위)는 모두 코드에서 쓰인다.
- 코드에 없는 몬스터 11종(`THE_ARM` 등)은 이미 `isPublicBestiaryMonster`로 숨겨져 있다.
- 다채로운 철학자들은 게임에서 선택지가 3개만 나온다. 자기 캐릭터를 뺀 해금 풀(풀 포함)을 고정 순서로 모아 무작위로 지운다.
  백과사전은 6색을 다 보여준다. 이것은 "무작위로 그중 3개"라는 별도 표기 문제라서 이 표식과 섞지 않는다.

## 요구사항

1. **판정 데이터는 생성한다.** 손으로 목록을 적지 않는다.
   - `scripts/extract-code-relations.py`와 같은 방식으로 디컴파일 소스를 읽는다.
   - 이벤트 선택지·페이지 키, 그리고 클래스가 없거나 쓰이지 않는 파워·전투 등을 `data/sts2/` 아래 JSON 하나로 낸다.
   - 동적 키를 고려한다:
     - 문자열 조합: `$"...{n}"`, `+ id`
     - 헬퍼 함수: `InitialOptionKey`, `RelicOption<T>`
     - 예: 심연의 욕탕 `LINGER{n}`, 거대한 꽃 `_1`, 미끄러운 다리 `HOLD_ON_n`, 진실의 석판 `DECIPHER_n`, 무한의 컨베이어 `ALL.options.<접시>`
   - 동적 키는 오탐으로 분류하지 않는다. 위 표가 정답 대조 기준이다.
   - `pnpm codex:relations`(slseoun-patch 9번 단계)에 넣어 패치마다 다시 뽑는다.
2. **표시는 항목 단위로 한다.** 같은 표식과 같은 툴팁 문구를 모든 자리에서 재사용한다.
   - 이벤트: 해당 선택지 프레임(`GameChoiceFrame`)과 결과 페이지 본문.
   - 파워·전투: 목록 타일, 상세 제목 옆, 호버 미리보기.
   - 관련 리소스 레일과 검색 결과에도 같은 표식을 단다.
3. **툴팁 문구**: "게임에서는 볼 수 없는 데이터마이닝 결과" 계열.
   - 정확한 문구는 사용자에게 받는다. 받은 문구는 그대로 쓴다.
   - 서비스 언어 ko·en을 둔다. 게임 언어 페이지는 en을 쓴다.
   - 툴팁은 게임식 호버팁(`GameUiHoverTip`)을 쓰고, 터치 기기에서도 열 수 있어야 한다.
4. **표식 모양**은 기존 백과사전 배지 체계를 따른다(베타 이미지 표시, 폐기 회색 처리 등). 폐기(`deprecated`)와는 다른 의미다.
   - 폐기: 예전 게임에 있었다.
   - 이번 표식: 게임에 한 번도 나온 적 없다(현재 빌드 기준).
   - 둘을 같은 회색 처리로 묶지 않는다.
5. **버전 경계**: 나중 패치에서 게임이 그 항목을 쓰기 시작하면 표식이 자동으로 사라져야 한다(1번의 재생성으로).
   과거 버전 페이지에서는 판정을 따로 하지 않는다. 현재 빌드 판정만 쓴다.
6. **QA**: 위 표의 모든 항목에 표식과 툴팁이 뜨는지 확인한다. 정상 항목 몇 개에 표식이 없는지도 확인한다.
   - 정상 예: 다채로운 철학자들 `IRONCLAD`, 심연의 욕탕 `LINGER3`.
   - 확인 범위: 로컬 dev, ko·en, 모바일 폭.
   - Supabase 차단 규칙은 `qa-supabase-load` 메모를 따른다.

## 정하지 않은 것 (사용자 결정)

- 툴팁 정확한 문구.
- 표식 위치·모양(아이콘인지 글자 배지인지).
- 평등 등 개별 항목을 아예 지울지. 이 작업 범위가 아니다.
