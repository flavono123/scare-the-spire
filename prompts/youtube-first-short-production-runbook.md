9. 1초·댓글 시작 시점·마지막 1초를 확인한다.

## 캡컷 안팎의 역할

| 작업 | 캡컷 안에서 | 밖에서 준비 |

| 9:16 캔버스·배경·텍스트·위치 | 가능 | 불필요 |

| 댓글 시작 시점에 등장 | 타임라인 배치로 가능 | 불필요 |

| 여러 TTS·BGM 트랙 | 가능 | 음원 파일 필요 |
| 사이트 sine/jitter·GameHoverTip | 그대로는 불가 | 첫 형식에서는 제외 |
| 재사용 템플릿 | 프로젝트 복제로 가능 | 원본 프로젝트 보존 |

않았다. 첫 편은 텍스트 범위 색상으로 검증했고, 실제 대본은 자동 캡션을
만든 뒤 현재 어절 범위를 수정하는 방식부터 시험한다.

## TTS 공급처와 비용

### 삐뚤어진 찬구

- 공급처: 타입캐스트
- 공식 웹 캐릭터 ID: `6010088f885570093ad24d53`
- 에디터:
  `https://studio.typecast.ai/text-to-speech?actor_id=6010088f885570093ad24d53&lang=ko`
- 웹 Basic: 월 9,900원, 상업 이용 가능, 속도 조절 없음
- 웹 Plus: 월 29,000원, 상업 이용·속도 조절 가능
- 첫 최종본 권장: Plus

무료 플랜 결과물은 최종 유튜브 파일에 쓰지 않는다. 로그인 후 같은
문장으로 속도를 여러 번 미리 듣고, 다운로드 직전에만 크레딧을 쓴다.

### 경태·유나·승표

세 이름은 타입캐스트 캐릭터가 아니라 NAVER CLOVA Voice의 공식
speaker다.

- 경태: `nkyungtae`
- 유나: `nyuna`
- 승표: `nseungpyo`

파일 제작에는 실시간 CLOVA Voice API를 쓰면 안 된다. 공식 정책상 API
응답 음원을 저장·편집·재사용할 수 없다. 파일 다운로드와 상업 이용을
지원하는 NCP CLOVA Dubbing 유료 빌더를 사용한다.

- Standard: 월 19,900원, VAT 별도(21,890원)
  - 프로젝트 20개
  - 다운로드 40회
  - 30,000자
- Premium: 월 89,900원, VAT 별도(98,890원)
- 첫 쇼츠에는 Standard면 충분하다.
- 프로젝트 그룹을 보유한 기간만 일할 과금되므로 사용하지 않으면
  프로젝트 그룹을 삭제한다.

아직 운영자 계정에서 CLOVA Dubbing 빌더의 세 목소리를 직접 청음하지
못했다. 결제 전에 무료 화면 또는 유료 빌더에서 이름과 음색이 치즈
후원 UI와 같은지 확인한다. 비슷한 다른 목소리로 바꾸지 않는다.

최소 월 표시 가격은 타입캐스트 Plus 29,000원 + CLOVA Dubbing Standard
19,900원(VAT 별도)이다. NCP VAT를 포함하면 50,890원이며 타입캐스트
결제 단계의 세금 표시는 별도로 확인한다.

Steam 게임·사운드트랙 구매는 음원 파일 접근 권한이지 유튜브 영상의
동기화 이용 허가가 아니다. Bandcamp 표기는 `all rights reserved`이고,
공식 YouTube 배포는 DistroKid를 사용하므로 Content ID 클레임 가능성이
있다. 권리자의 별도 허가를 확인하기 전에는 업로드 권리가 미확정이다.
게시 전에 무음 또는 라이선스가 명확한 대체 BGM 버전도 보관한다.
