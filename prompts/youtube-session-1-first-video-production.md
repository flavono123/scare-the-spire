## 1. 캡컷 — 설치, 템플릿, 캡컷만으로 되는지

공식 데스크톱: https://www.capcut.com/ko-kr/tools/desktop-video-editor  
Mac: macOS 10.14+. 크랙/미러 사이트 금지.

조사·실행할 것:

- 데스크톱에서 **커뮤니티 템플릿 마켓은 거의 없다**. 이 채널의 “템플릿”은 캡컷 마켓 템플릿이 아니라 **완성된 프로젝트를 복제**하는 것이다. `파일 → 복제` 또는 프로젝트 폴더 복사. 자막 스타일 프리셋이 있으면 그것도 저장한다.
- **캡컷 안에서 가능한 것**: 9:16 캔버스, 단색/이미지 배경, 텍스트 레이어(폰트·색·위치·등장 애니메이션), 자동 캡션 생성 후 위치/색 수정(현재 단어 골드), 여러 오디오 트랙(TTS + BGM), 이미지·모자이크/블러, 1080×1920보내기.
- **캡컷 안에서 안 되는 것 / 하면 안 되는 것**:
  - 치즈와 같은 삐뚤어진 찬구·경태·유나·승표 합성. 캡컷 내장 TTS는 다른 목소리다. **wav를 밖에서 만들어 가져온다.**
  - 사이트 `GameHoverTip`, rich text sine/jitter. 첫 편에서는 금색 어절 강조면 충분.
  - 모바일 전용 “템플릿 링크 공유”.
- 자동 캡션을 하단에만 두면 공감입니다가 아니라 흔한 TTS 쇼츠가 된다. 본문 글자를 **중앙**으로 옮기는 법을 템플릿에 고정한다.
- 노래방(어절 단위 하이라이트)은 자동 캡션 + 현재 단어 색, 또는 텍스트 복제 레이어를 오디오 파형에 맞춰 자르는 방식. 둘 중 운영자가 반복 가능한 쪽을 고르고 그 절차를 적는다.

산출물: `첫 쇼츠 v1` 캡컷 프로젝트 + 운영자가 따라 할 짧은 체크리스트(설치 → 복제 → wav 교체 → 본문/댓글 텍스트 교체 → 보내기).

## 2. TTS — 치즈 도네 목소리, 속도 포함해서 파일로 만들기

### 고정 사실 (이 세션이 뒤집지 말 것)

- 목소리는 **치지직 치즈 채팅 후원 UI에서 고르는 이름**이 정본이다. 이전 계획의 호빈이·채린이·그냥 찬구는 폐기.
- 타입캐스트가 치지직 치즈 TTS 엔진을 공급한다고 타입캐스트가 직접 밝혔다.  
  https://typecast.ai/kr/learn/streaming-tts-api-ttfb/
- 치즈 후원 메시지는 **100자** 제한이 있다. 쇼츠 대본을 치즈에 쪼개 후원하는 방식은 제작 파이프라인이 될 수 없다.
- 스트리머 스튜디오(방송 관리 → 알림 → 채팅 후원)에는 TTS **속도** 슬라이더가 있다. 그건 방송 송출용이다. 유튜브 파일 추출용이 아니다.  
  https://help.naver.com/service/30044/contents/23031
- 남의 방송(중괄호 포함)에서 후원음을 녹음하거나, 치즈에 후원해서 음원을 수확하거나, 네이버 비공개 TTS 엔드포인트를 뜯지 않는다.

### 해야 할 조사 (추측으로 캐스트를 바꾸지 말 것)

1. 치즈 채팅 후원 화면에서 네 이름이 **실제로 목록에 있는지** 확인한다. 운영자에게 목록 스크린샷을 받거나, 공개된 최신 목록을 찾는다. 매직 보이스(스트리머 클론)는 쓰지 않는다.
2. 타입캐스트 웹 에디터(캐릭터 캐스팅 검색)에서 **삐뚤어진 찬구 / 경태 / 유나 / 승표**를 찾는다.
   - API 문서 542개 한국어 표기에는 `Salty Chan-gu = 삐뚤어진 찬구`가 있다. **경태·유나·승표는 그 표에 없다.** 웹 에디터·구 로스터·치즈 전용 라벨일 수 있다. 이름만 같다고 다른 캐릭터를 쓰지 않는다.
   - 서드파티 카탈로그에는 `nkyungtae=경태`, `nyuna=유나`, `nseungpyo=승표` 같은 코드가 보인다. 타입캐스트 공식 `voice_id`와 같은지 **에디터에서 들어보고** 확정한다.
3. 속도:
   - 타입캐스트 유료 **플러스**부터 웹 속도 조절. API는 `output.audio_tempo` 0.5–2.0 (기본 1.0). 플러스 미만은 속도 UI가 잠길 수 있다.  
     요금: https://typecast.ai/kr/pricing  
     API: https://typecast.ai/docs/ko/api-reference/text-to-speech/text-to-speech
   - 삐뚤어진 찬구의 감정(기쁨/슬픔/화남)은 프로 플랜의 감정 조절일 수 있다. 웹에서 잠기는지 확인한다. 첫 편은 감정 없이 속도만으로도 된다.
   - 승표가 느리면 `audio_tempo`를 1.2–1.5부터 시험한다. 캡컷에서 클립 배속은 피치가 올라가므로 **최후 수단**.
   - 치즈 방송 속도 슬라이더와 타입캐스트 tempo가 같은 체감인지도 적는다. 운영자가 치즈에서 익숙한 빠르기를 타입캐스트 숫자로 대응시킨다.
4. 자막 싱크: 타입캐스트 타임스탬프 TTS(`with-timestamps`)는 나중 자동화용. 첫 편은 wav + 캡컷 자동 캡션으로 충분하다.
5. 라이선스: 타입캐스트 **유료**만 상업 이용. 무료는 출처 강제·비상업. 유튜브 업로드는 유료로 가정한다. 미리듣기/재생성은 크레딧이 안 깎이고, 다운로드 때 깎인다.

추천 제작 경로 (조사로 뒤집히면 문서에 이유를 적고 바꾼다):

1. 타입캐스트 웹에서 네 캐릭터를 캐스팅한다. 문장 단위로 생성한다.
2. 본문=삐뚤어진 찬구, 댓글=경태/유나/승표 교차.
3. 속도를 쇼츠에 맞게 올리고 wav로 받는다.
4. 캡컷 타임라인에 순서대로 붙인다.

치즈에 후원해서 녹음하는 경로는 “같은 목소리인가” 검증용 샘플 한 줄 이상은 하지 않는다.

산출물: 목소리 대응표(치즈 이름 → 타입캐스트 캐릭터명 → voice_id 또는 웹 URL → 권장 tempo → 플랜). 못 찾으면 찾은 것과 못 찾은 것을 분리하고, 운영자에게 치즈 목록 확인을 요청한다. 비슷한 목소리로 임의 대체하지 않는다.

## 작업 순서

1. 캡컷 설치 여부 확인. 없으면 공식 링크로 안내하고 설치를 기다린다.
2. TTS 대응표를 먼저 연다. 목소리가 안 맞으면 화면 템플릿만 만들어도 되지만, 첫 결과물의 목소리는 이 캐스트가 아니면 실패다.
3. STS1 설치 폴더에서 The City / Level2 음원을 찾는다.
4. 캡컷 템플릿 v1: 배경, 상단 워드마크, 중앙 본문, 댓글 레일, TTS 자리, BGM 자리.
5. 더미 대본 한 편을 내보낸다. 가능하면 화면을 확인한다.

사이트 레포에 캡컷 프로젝트나 wav를 커밋하지 않는다. 음원·영상은 운영자 로컬. 이 레포에는 절차 문서만 필요하면 `prompts/`에 짧게 보완한다. `pnpm static:data` 산출물은 커밋하지 않는다.

한국어로 운영자에게 보고한다. 코드/주석이 필요하면 영어.
